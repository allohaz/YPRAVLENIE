# GestureTouch 0.2

Android-приложение (Kotlin): управление телефоном мимикой, головой, руками и голосом без касаний.
Написано без возможности собрать и проверить на устройстве, первая сборка может потребовать правок.

## Как это работает

```
Фронтальная камера (CameraX, 320x240, до 30 FPS)
   ├─ MediaPipe Face Landmarker  → наклон головы, брови, рот
   └─ MediaPipe GestureRecognizer → позы рук + взмахи ладонью
        ↓ HoldTracker: порог + удержание + пауза между срабатываниями
        ↓ событие Gesture
GestureAccessibilityService → выбирает профиль по приложению на экране
        → свайп/тап/двойной тап, нажатие по тексту кнопки, ввод текста,
          запуск приложения, Назад/Домой/Недавние, цепочки действий

Голос: указательный палец вверх (или кнопка в уведомлении/в приложении) → SpeechRecognizer слушает одну фразу
        → VoiceRouter → то же самое исполнение действий
```

## Энергопотребление

- Нажал **Стоп** (или «Стоп» в уведомлении): `CameraService` уничтожен, камера, модели и микрофон освобождены.
  Остаётся только включённая служба спец. возможностей: она реагирует лишь на смену окна. Хочешь ноль совсем:
  кнопка «Полностью выключить» (потом службу надо включить заново в настройках).
- Пока работает:
  - экран выключен или заблокирован → камера отвязана;
  - 8 с без лица и руки → FPS падает до 5, лицо или рука появились → сразу полный FPS;
  - пауза жестов → лицо не считается, рука на 4 FPS (чтобы поймать «продолжить»);
  - GPU-делегат, кадр 320x240, руки считаются в каждом 2-м кадре.
- Всё в `settings` конфига. Реальный расход мерь сам: Настройки → Батарея.

## Жесты (от частых и лёгких к редким)

Оставлены только лёгкие и надёжные. Убраны: долгое закрытие глаз, подмигивания (многие не могут одним глазом),
улыбка (срабатывает, когда смеёшься над видео), повороты головы (отворачиваешься от экрана),
ладонь, «рога», взмахи вверх/вниз (дублировали бы наклоны головы).

| # | Жест | Дом. экран | TikTok | MLBB | Везде |
|---|---|---|---|---|---|
| 1 | Наклон головы вправо | | следующее видео | | |
| 2 | Большой палец вверх | запуск TikTok | лайк | быстрое сообщение | |
| 3 | Наклон головы влево | | предыдущее видео | | |
| 4 | Кулак | запуск MLBB | пауза/пуск видео | кнопка 4 | |
| 5 | Брови вверх | | комментарии | кнопка 3 | |
| 6 | Взмах рукой влево | | Назад | | |
| 7 | Открытый рот | | «Поделиться» | кнопка 1 | |
| 8 | Указательный палец вверх | | | | голосовая команда |
| 9 | Знак мира (держать 0.8 с) | | | | пауза/продолжить жесты |
| – | Большой палец вниз, взмах вправо | свободны | свободны | свободны | |

В каждом профиле одно действие = один жест, дублей нет. Наклоны головы в MLBB не заняты:
они зарезервированы под джойстик движения.

Наклон головы считается от нейтрального положения, которое подстраивается само (~4 с),
поэтому лёжа на боку или с наклонённым телефоном ложных наклонов быть не должно.

## Голос

- Говорить: указательный палец вверх, кнопка «Говорить» в уведомлении или кнопка в приложении. Слушает одну фразу до 10 секунд.
- «открой <приложение>» — по алиасам из `apps` или по названию установленных приложений.
- «тикток друзья / главная / входящие / профиль» — откроет TikTok, если не открыт, и нажмёт вкладку.
- «домой», «назад», «недавние», «шторка», «пауза», «комментарий огонь» (пример цепочки).
- Нужны: приложение Google (служба распознавания) и загруженный русский офлайн-пакет. Постоянное прослушивание не включено намеренно: оно заметно сажает батарею.

## config.json

Правится в приложении («Настройки») или на компьютере через импорт/экспорт. Разделы:
`settings` (FPS, GPU, зеркалирование…), `gestures` (удержание, пауза, порог каждого жеста), `global`,
`profiles` (на приложение: `packages`; `@home` = рабочий стол), `apps` (алиасы для голоса), `voice`.

Действия (`type`): `swipe`, `tap`, `doubleTap`, `longPress` (координаты доли экрана 0..1), `openApp`,
`clickText` (подстрока текста/описания элемента, можно список вариантов), `setText`, `wait`, `seq`,
`back`, `home`, `recents`, `notifications`, `pause`, `listen`.

## Сборка на GitHub (без Android Studio)

1. Залей содержимое проекта в корень репозитория (`settings.gradle.kts` должен лежать в корне, не в подпапке). Файл `.github/workflows/build.yml` обязателен.
2. Вкладка **Actions** → «Build APK» → дождись зелёной галочки (5-10 минут). Можно запустить вручную: Run workflow.
3. Открой завершённый запуск → внизу **Artifacts** → `GestureTouch-apk` → скачай zip, внутри `app-debug.apk`.
4. Перекинь APK на телефон и установи. Модели скачиваются при сборке, вручную класть не нужно.

## Как запустить (пошагово)

**На компьютере**
1. Установи Android Studio (последняя версия, JDK и SDK 34 ставятся вместе с ней).
2. Распакуй архив, `File → Open` и выбери папку `GestureTouch`. Дождись Gradle Sync. Если предложит обновить Gradle или плагин, соглашайся.
3. Скачай две модели (ссылки в `app/src/main/assets/PUT_MODELS_HERE.txt`) и положи в `app/src/main/assets/` с теми же именами:
   `face_landmarker.task` и `gesture_recognizer.task`.

**Поставить на Poco X5 Pro** (способ А или Б)
- А (кабель): на телефоне Настройки → О телефоне → 7 раз нажать на версию MIUI/HyperOS → Дополнительные настройки → Для разработчиков →
  включить «Отладка по USB» и «Установка через USB» (Xiaomi может попросить войти в Mi-аккаунт). Подключи телефон кабелем,
  разреши отладку, в Android Studio выбери телефон и нажми ▶ Run.
- Б (файл): `Build → Build APK(s)`, скопируй `app-debug.apk` на телефон, открой и разреши установку из этого источника.
  Тогда в Android 13+ переключатель службы спец. возможностей может быть серым: Настройки → Приложения → GestureTouch →
  ⋮ (три точки вверху) → «Разрешить ограниченные настройки».

**В приложении GestureTouch (один раз)**
1. Кнопка 1 → в списке найди GestureTouch → включи и подтверди.
2. Кнопка 2 → разреши «Поверх других окон».
3. ▶ Старт → разреши камеру, микрофон, уведомления.
4. Настройки Poco из раздела ниже (автозапуск, батарея, окна в фоне).

**Проверка по порядку** (пробуй в таком порядке, чтобы понять, что именно не работает)
1. Рабочий стол → большой палец вверх → должен открыться TikTok.
2. В TikTok наклон головы вправо/влево → следующее/предыдущее видео. Если стороны перепутаны, `swapSides: true`.
3. Большой палец вверх → лайк, кулак → пауза.
4. Указательный палец вверх → вибрация и «Говори…» → скажи «открой телеграм».
5. Если жесты срабатывают слишком редко или слишком часто, правь `th` и `hold` в Настройках.

**Залить на GitHub**
```
cd GestureTouch
git init && git add . && git commit -m "GestureTouch 0.2"
git branch -M main
git remote add origin https://github.com/<ты>/GestureTouch.git
git push -u origin main
```
Модели (по ~4-8 МБ) можно закоммитить или добавить в `.gitignore` и описать скачивание в README.

## Poco / HyperOS

- Автозапуск: включить; батарея: «Нет ограничений»; закрепить в недавних.
- Для запуска приложений жестом: Настройки → Приложения → GestureTouch → Другие разрешения → «Запуск в фоне / Всплывающие окна в фоне» разрешить.
- После перезагрузки телефона нажми Старт снова (Android 14 не даёт запускать камеру из автозагрузки).

## Ограничения

- Задержка: ~50-100 мс на кадр плюс удержание жеста (150-350 мс). Короче удержание → быстрее, но больше ложных срабатываний.
- `clickText` зависит от подписей кнопок в приложении (в TikTok они могут меняться): проверь на своей версии и язык интерфейса.
- MLBB: только отдельные кнопки по координатам, подгони под свою раскладку. Автоматические нажатия в игре могут нарушать правила, используй на свой риск и не в рейтинге.
- Зелёная точка камеры горит, пока сервис работает.
